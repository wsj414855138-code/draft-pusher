# 微信公众号后台 · DOM 速查与坑点

> 全部为 2026-09 ~ 10 月实测记录。平台改版会让选择器失效——排查方法见文末。

## 一、三个关键参数（踩坑最多的地方）

| # | 参数 | 值 |
|---|---|---|
| 1 | **URL 必须带 `token`** | 不带一律跳「登录超时，请重新登录」，**哪怕登录态有效**。token 每次会话会变，从任意后台页 URL 里取 |
| 2 | **贴图编辑器是 `appmsg_edit_v2`** | `/cgi-bin/appmsg?t=media/appmsg_edit_v2&action=edit&isNew=1&type=77&createType=8&token=<T>`<br>⚠️ `appmsg_edit` + `type=77` 是**图文**编辑器（长得完全不一样） |
| 3 | **草稿箱/发表记录分两类** | `type=77`=贴图，`type=10`=历史图文素材。发表记录页加 `show_type=8` 直达贴图视图 |

## 二、贴图编辑器 DOM 速查

| 元素 | 选择器 | 说明 |
|---|---|---|
| 图片上传区 | `div.image-selector__add` | **只吃 drop 事件**，click 不唤起文件框；页面上那两个 `input[type=file]` 属于富文本工具栏，**不是贴图的** |
| 标题 | `div.ProseMirror[0]` | `textarea.js_title` 只是隐藏镜像，写它无效；限 20 字 |
| 描述 | `div.ProseMirror[1]` | 限 1000 字 |
| 链接行 | `div.wording`（`cursor:pointer`） | 点它才展开 `内容链接/小程序/小店商品` |
| 链接输入 | `input.weui-desktop-form__input` | 第 0 个=小程序链接，第 1 个=卡片标题 |
| 存草稿 | 文案 `保存为草稿` 的元素 | |
| 发表 | 文案 `发表` 的元素 | |
| 引导弹窗 | `.education-dialog` | 话题卡片/小店返佣/未授权切换账号——会遮挡按钮导致保存静默失败，**上传前、保存前各清一次** |

## 三、坑点清单（全部实测踩过）

| # | 坑 | 症状 | 正解 |
|---|---|---|---|
| 1 | **ProseMirror 吞掉 `\n`** | 描述变成一坨无换行长文 | **逐段 `Input.insertText` + 段间按 Enter**（生成 `<p>` 段落） |
| 2 | **受控 input 里 Cmd+A 失效** | 只删光标处一个字符，新旧值粘一起 | 原生 setter：`Object.getOwnPropertyDescriptor(HTMLInputElement.prototype,'value').set.call(el,'')` + `dispatchEvent(new Event('input',{bubbles:true}))` |
| 3 | **小程序链接缺 `#`** | 报「请输入正确的小程序的链接」 | 必须 `#小程序://名称/xxx` 格式 |
| 4 | **链接行点不动** | 点「链接」那行没反应 | 可点的是行内 `div.wording`（`cursor:pointer`），不是行本身 |
| 5 | **批量流程里插链接会失败** | 单独跑成功，合进循环就失败 | **内容推送与插链接分开跑**（面板展开时序对不上） |
| 6 | **点完「无需声明并发表」≠ 成功** | 弹窗关了但啥也没发生 | 必须回「发表记录」核实；静默失败要翻**页面尾部**找小字提示 |
| 7 | **发表记录页卡片无统一类名** | 选择器拿不到 | 用 `innerText` 按行解析：`时间/状态/标题/6个数字` |
| 8 | **运营者微信验证** | 发表被静默拦下 | 页面最底部有「微信验证 · 扫码后请联系管理员」→ **必须人工扫码** |
| 9 | **本地 curl 被代理挡** | 连不上 127.0.0.1 | 加 `--noproxy '*'`（环境有 `HTTP_PROXY` 时） |
| 10 | **zsh 通配符** | `--remote-allow-origins=*` 报 no matches | 加引号 `'--remote-allow-origins=*'` |
| 11 | **贴图发表与「群发通知」脱钩** | 曾以为点「发表」= 立即群发 | 事实：贴图发表**无需开启群发通知、不占用账号的群发通知次数、不推送粉丝**（后台「已发表」悬停浮窗原话）。发表动作仍应人工把关 |
| 12 | **后台标签里拖拽上传无效** | 图片 `0/7`，正文却正常 | 拖拽（`Input.dispatchDragEvent`）只在前台标签可用；后台标签改用 `DOM.setFileInputFiles` 给隐藏的 `<input type=file multiple>` 注入 |
| 13 | **图片计数别数 `img` 元素** | 报 `0/N` 假阴性 | 读 `.image-selector` 的「已就绪 总数」文本（如 `7 7`）；`img` 元素懒加载会漏计 |

## 四、发表记录（数据回收）的 innerText 结构

`mp_fetch_stats.mjs` 依赖的结构（实测）：

```
<时间，如"今天 22:23"或"10月6日">
<状态，如"已发表">
<标题>
<阅读> <分享> <留言> <点赞> <收藏> <转发>   ← 连续 6 个纯数字
<下一条时间> ...
```

解析法：逐行扫，遇到时间行 → 接下来 3 行是 状态/标题 → 之后连续 6 个纯数字是指标。

## 五、图文（news）编辑器 · 已探明要点

> 来自编辑器探针实测（`t=media/appmsg_edit_v2&...&type=10`）。
> 完整推送脚本未固化，以下要点供继续开发时参考。

- **标题**：仍是 `div.ProseMirror[0]`
- **正文**：`div.ProseMirror[1]`，两种注入都实测可行：
  - `document.execCommand('insertHTML', false, '<p>...</p>')`
  - `ClipboardEvent('paste')` 派发（带 `text/html`）
- **封面**：页面有「拖拽或选择封面」文字入口 / `.select-cover_multi_drop` / `.js_cover_btn_area`；点击后弹选择框
- **插图**：工具栏「图片」按钮（`.js_imagedialog` 或文字为「图片」的小尺寸元素）
- **正文字数**：页面右下角文本 `正文字数 N`
- **清除正文**：聚焦后 Cmd+A（`modifiers: 4`）+ Backspace

## 六、账号类型速查（实测）

| | 订阅号 | 服务号 |
|---|---|---|
| 贴图发布 | ✅ | ✅ |
| 静默发表（不通知粉丝） | 不限次 | 不限次 |
| 群发通知额度 | **1 次/天** | **4 次/月** |
| 带小程序卡片 | 需账号已关联该小程序 | 同样需关联 |

> ⚠️ 「服务号频道」是微信把贴图做成的**内容频道名**，不是账号类型——订阅号发的贴图同样进这个推荐池。

## 七、平台改版排查法

1. `node scripts/cdp.mjs shot /tmp/before.png` 截图看现状
2. `node scripts/mp_bg.mjs --url "<后台URL>" --frames` 看页面结构（是否多了 iframe）
3. 用 `--show "<js>"` 在页面里试选择器，找到新选择器再改脚本
4. 改完先推 1 篇测试内容核实，再批量
